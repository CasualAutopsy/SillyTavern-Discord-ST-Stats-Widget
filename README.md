# Discord-ST-Stats-Plugin
Plugin for updating a SillyTavern stats widget for Discord.

## Prerequisites
- Node.js
- SillyTavern
- Git
- A Discord Account
- To setup your own Discord widget beforehand. [Learn how here](https://chloecinders.com/archived/discord-widgets).

## Installation
1. If you haven't already, open the the SillyTavern `config.yaml` file and change `enableServerPlugins` to `true`.
2. Open the terminal in the SillyTavern directory and run the following commands:
```bash
cd plugins
git clone https://github.com/CasualAutopsy/SillyTavern-Discord-ST-Stats-Widget -b plugin
```
3. Go into the newly created `SillyTavern-Discord-ST-Stats-Widget` folder and fill in the `secrets.json` with the needed IDs and token.
4. Restart the SillyTavern server.
